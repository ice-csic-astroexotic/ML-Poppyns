# Magneto-rotational + detection simulation example
This is an example of magneto-rotational plus detection simulation run with the `simulate_population_magrot_det.py` script and using the default parameters in the configuration file.

To run this example we then use the following command:
```commandline
python pypopsyn/simulator/simulate_population_magrot_det.py --dyn_data data/example_simulation_dyn --output_dir data/example_simulation_magrot_det
```
