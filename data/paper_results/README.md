# Paper results data

This folder contains the data necessary to reproduce the results and plots in our papers:
- [Ronchi et al. 2021](https://ui.adsabs.harvard.edu/abs/2021ApJ...916..100R/abstract)
- [Graber et al. 2024](https://ui.adsabs.harvard.edu/abs/2023arXiv231214848G/abstract)

The notebooks used to analyze these data and produce the plots are located in the directory `paper_plots`, in the folders 
`ronchi_etal_2021` and `graber_etal_2024`, respectively.
