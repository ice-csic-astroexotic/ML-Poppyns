# Inference example

This is an example of statistical inference using a convolutional neural network.

To run this example, we use the following command:
```commandline
python mlpoppyns/learning/infer_nn.py --trained_model data/example_learning_nn/models/Convolution/20240926_113426/best_model_trial1.pth
```
By default, this script will use the configuration specified in `mlpoppyns/learning/config_multiparameter_CNN.json`.
